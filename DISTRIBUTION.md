# Distribution and third-party notices

Aura Music Player's Android application source remains private. Public access to
the signed APK does not publish or grant an open-source license to the Aura
application source. This repository contains only distribution documentation and
metadata, not a source mirror.

Third-party libraries retain their own licenses and copyrights. The closed-source
description does not restrict rights those licenses grant. Obtain the accompanying
third-party notices with the APK; those notices are not application source.
The separate Aura Server stack has its own public source/licenses.

No production signing key or signing password is stored here or in GitHub Actions.
Official releases are signed locally using the maintained Android update identity.
The certificate fingerprint is public verification material, not a private key.

Independent final licensing/security review remains a beta release qualification.
This notice is not a claim of an independent legal opinion or security certification.
